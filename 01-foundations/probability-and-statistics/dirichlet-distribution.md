## Core Idea

The Dirichlet distribution is the generalization of [[beta-distribution]] to $k$
categories. Where Beta models uncertainty about a single probability $p$ (two
outcomes), Dirichlet models uncertainty about an entire probability vector
$[p_1, p_2, \ldots, p_k]$ that sums to 1. It is the **conjugate prior for the
Multinomial distribution** and is the foundation of Latent Dirichlet Allocation
(LDA) — the standard topic model in NLP.

## Details

### Parameters

- $\boldsymbol{\alpha} = [\alpha_1, \alpha_2, \ldots, \alpha_k]$ — concentration
  parameters, interpreted as pseudo-counts for each category (all $\alpha_i > 0$)
- Output: a vector $[p_1, \ldots, p_k]$ where each $p_i \geq 0$ and $\sum p_i = 1$
  (a point on the probability simplex)

### PDF

$$f(\mathbf{p}; \boldsymbol{\alpha}) = \frac{1}{B(\boldsymbol{\alpha})} \prod_{i=1}^k p_i^{\alpha_i - 1}$$

where $B(\boldsymbol{\alpha}) = \frac{\prod_i \Gamma(\alpha_i)}{\Gamma(\sum_i \alpha_i)}$
is the multivariate Beta function — the normalizing constant.

### Expectation

$$E[p_i] = \frac{\alpha_i}{\sum_j \alpha_j}$$

Each component's expected probability is its share of the total alpha.
Example: $\boldsymbol{\alpha} = [2, 3, 5]$ → $E[\mathbf{p}] = [0.2, 0.3, 0.5]$.

### Concentration Parameter Effect

When all $\alpha_i$ share a common value $\alpha_0$:

```
alpha_0 < 1   ->  sparse: samples concentrate at corners (one category dominates)
alpha_0 = 1   ->  uniform: all probability vectors equally likely
alpha_0 >> 1  ->  dense: samples concentrate near center (all categories equal)
```

This is how LDA controls topic sparsity: small $\alpha$ → each document uses
few topics; large $\alpha$ → documents mix many topics evenly.

### Relationship to Beta

$$\text{Beta}(\alpha, \beta) = \text{Dirichlet}([\alpha, \beta])$$

Beta is the special case with $k=2$. All Beta intuitions carry over.

### Conjugate Prior for Multinomial

Prior $\text{Dirichlet}(\boldsymbol{\alpha})$. Observe counts $\mathbf{n} = [n_1, \ldots, n_k]$:

$$\text{Posterior: } \text{Dirichlet}(\alpha_1 + n_1,\; \ldots,\; \alpha_k + n_k)$$

Just add the observed counts to the prior — same closed-form update as Beta-Binomial.

### LDA Topic Models

Latent Dirichlet Allocation uses two Dirichlet priors:

```
theta_d ~ Dirichlet(alpha)   — topic mixture for document d
phi_t   ~ Dirichlet(beta)    — word distribution for topic t
```

Each word is generated by: sample a topic from theta_d, then sample a word
from phi_t. The Dirichlet priors control sparsity at both levels.

## Code Example

```python
import numpy as np

def dirichlet_sample(alpha: list, n_samples: int) -> np.ndarray:
    """Sample from Dirichlet(alpha). Each row sums to 1."""
    return np.random.dirichlet(alpha, size=n_samples)

# E[X_i] = alpha_i / sum(alpha)
alpha = [2.0, 3.0, 5.0]
samples = dirichlet_sample(alpha, n_samples=100000)
expected = np.array(alpha) / sum(alpha)
print(f"E[p] expected: {expected}")
print(f"E[p] observed: {samples.mean(axis=0).round(4)}")
print(f"Each row sums to 1: {np.allclose(samples.sum(axis=1), 1.0)}")

# Concentration effect
for a0 in [0.1, 1.0, 10.0]:
    s = dirichlet_sample([a0, a0, a0], n_samples=5)
    print(f"\nalpha_0={a0} — sample rows:")
    for row in s:
        print(f"  {row.round(3)}")

# Conjugate update: Multinomial posterior
alpha_prior = np.array([1.0, 1.0, 1.0])  # uniform prior
observed_counts = np.array([10, 30, 60])  # observed data
alpha_posterior = alpha_prior + observed_counts
print(f"\nPosterior alpha: {alpha_posterior}")
print(f"Posterior mean:  {alpha_posterior / alpha_posterior.sum()}")

# LDA-style: sample topic mixtures for 3 documents
alpha_doc = [0.1, 0.1, 0.1]  # sparse — few topics per doc
topic_mixtures = dirichlet_sample(alpha_doc, n_samples=3)
print("\nDocument topic mixtures (sparse alpha=0.1):")
for i, mix in enumerate(topic_mixtures):
    dominant = np.argmax(mix)
    print(f"  Doc {i}: {mix.round(3)}  — dominant topic: {dominant}")
```
