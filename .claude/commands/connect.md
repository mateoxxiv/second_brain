Analyze the vault and find missing connections between notes.

Follow these steps:

1. **Scan the vault**: Read all existing permanent and literature notes. Build a mental map of what topics exist and how they're currently linked.

2. **Find missing links**: Identify notes that reference concepts covered in other notes but don't link to them. For example, a note on "Backpropagation" that mentions "chain rule" but doesn't link to a "Chain Rule" note.

3. **Suggest bridge notes**: Identify conceptual gaps — pairs of notes that should be connected but need an intermediate note to bridge them. For example, "Linear Algebra" and "Neural Networks" might need a "Matrix Operations in Neural Networks" bridge note.

4. **Find orphan notes**: Notes with zero or very few incoming/outgoing links that might be isolated.

5. **Present findings**:
   - **Missing links**: "Note A should link to Note B because..."
   - **Bridge notes needed**: "A note on X would connect Y and Z"
   - **Orphan notes**: Notes that need to be better integrated
   - **Cluster analysis**: Which areas of the vault are well-connected vs sparse

6. **Ask the user**: Which connections to add and which bridge notes to create. Apply changes only after approval.
