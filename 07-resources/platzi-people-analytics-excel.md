## Summary

Platzi course on People Analytics for HR using Excel, AI, and dashboards. Covers the full analytics workflow applied to human resources data: from data collection and ethical handling, to KPI design, dashboard building, hypothesis validation, and long-term strategy. Uses Excel as the primary tool with AI-assisted analysis for qualitative data (exit interviews, satisfaction surveys).

## Key Takeaways

1. **People Analytics = applying data science to HR decisions** — employee retention, satisfaction, rotation, and recruitment can all be measured and optimized with the same ML/statistics toolkit used elsewhere.
2. **KPI-first design** — before touching data, define what metric you're trying to move and why. The dashboard is a consequence of the KPI, not the other way around.
3. **Ethics in HR data is non-negotiable** — people data is sensitive. Data classification, access control, and bias awareness are core skills, not afterthoughts.
4. **AI for qualitative data** — exit interviews and open-ended survey responses can be analyzed with AI (sentiment, clustering, topic extraction) to extract structured insights from unstructured text.
5. **Hypothesis-driven analytics** — frame HR questions as hypotheses (e.g., "high rotation correlates with low manager satisfaction scores") and validate with data before acting.

## My Thoughts

People Analytics is a direct application of the probability and statistics track (T3) and the data engineering track (B7) from the roadmap. The KPI → dashboard workflow is also foundational for any DS/AI role — every ML system eventually needs a monitoring dashboard. Excel is the entry-level tool here; the same concepts transfer directly to Python (pandas), SQL, and BI tools (Power BI, Tableau, Looker).

The AI-assisted qualitative analysis section is particularly relevant — it's essentially a RAG/embedding use case applied to HR data, which connects to B5 (RAG Pipeline) and B4 (Embeddings & Vector Search).
